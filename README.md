# 🗺️ DATA QUESTZ

DATA QUESTZ is an interactive learning game that teaches SQL database filtering using drag-and-drop gameplay.

## Features

- 🎮 Drag-and-drop record sorting
- 📚 SQL learning module
- 💡 Hint system
- 📊 Query Result table
- ⭐ Score and level progression
- ⏱ Timer and lives
- 🧠 Learning feedback

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Learning Outcomes

Students learn:

- SQL SELECT
- SQL WHERE
- AND conditions
- Boolean logic
- Database filtering

Developed for an Interactive Learning Innovation Competition.
